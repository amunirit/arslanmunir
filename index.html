Reflow Studio

Reflow Studio is a private publishing tool used by its owner to create and post educational videos to his own channels:

  • Happy Learners World: learning videos, worksheets, coloring pages and bedtime stories for young children.
  • Fluent Friends: English lessons for Urdu, Hindi and Arabic speakers.

It uses the YouTube Data API to upload videos, set titles, descriptions and playlists, and read basic statistics for the owner's own YouTube channels. It is not offered to the public and has no other users.
